# 关于

## 起源

起初，是在写我那个站点时，需要这么一个头像选择组件，那个时候我就是想要一个类似于手机微信头像选择的组件，但是找了半天也没有找到合适的，刚好那时候技术也学了七七八八，想着说不定我也能造一个轮子（现在想想那时候真是，技术还没学到家，就想和太阳肩并肩），所以就自己写了一个。

我看下这个库 1.0.0 发布时间是 2022年10月 距离 3.0.0-alpha.1 的 2025年6月 间隔约两年半。当初发布了 1.x 版本后，过了几个月，又发布了 2.x 后面因为各种各样的原因，不过主要还是遇到一个问题后，我老想着完美解决，但是又想不到完美解决的办法[苦笑]，久而久之就没动力继续开发了，后面也就没有继续更新。

当前版本采用与之前截然不同的设计理念：早期版本通过单一函数配合配置参数定义行为，而 3.x 版本改为提供组件与工具函数组合的松耦合方案。虽然旧版的函数式调用方式（调用函数即可异步获取处理完成的头像）更符合函数式编程思想，但新版通过在文档中提供了[函数式调用示例](/usage#结合-el-dialog-函数式调用)，便于开发者快速复用并自定义实现。
